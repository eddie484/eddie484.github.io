Memory Initialization File

Binary to MIF 변환기

한 줄에 하나씩 입력한 32비트 이진 명령어를 주소가 포함된 HEX MIF 형식으로 변환합니다.

WIDTH 32 DEPTH 8192 RADIX HEX

Input

32비트 이진 명령어

각 줄은 구분 기호를 제외하고 정확히 32비트여야 합니다.

0개 명령어

Output

HEX MIF

이진 명령어를 입력한 뒤 변환 버튼을 눌러 주세요.

Format guide

변환 규칙

01

이진수 정리

밑줄과 공백은 자동으로 제거하며, 빈 줄은 건너뜁니다.

02

HEX 변환

32비트 명령어를 8자리 대문자 HEX 값으로 변환합니다.

03

메모리 채움

마지막 명령어 이후부터 1FFF 주소까지 FC000000으로 채웁니다.
